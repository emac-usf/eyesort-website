# EyeSort Website

Source for [www.eyesort.org](https://www.eyesort.org), the public site for [EyeSort](https://github.com/emac-usf/EyeSort), an EEGLAB plugin for labeling synchronized fixation events in reading experiments.

Maintained by the Eye Movements & Cognition Lab at the University of South Florida.

## Contributing

Report website issues in this repository. Report plugin defects in the [EyeSort issue tracker](https://github.com/emac-usf/EyeSort/issues).
