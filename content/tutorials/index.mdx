# Tutorials

Learn how to use EyeSort with step-by-step tutorials covering common workflows and use cases.

## Available Tutorials

Browse our tutorials to learn specific EyeSort workflows:

- **[Quickstart Tutorial](/tutorials/quickstart)** - Complete walkthrough from data loading to BDF generation
- **[Full Pipeline Tutorial](/tutorials/full-pipeline)** - Detailed workflow including batch processing and ERPLAB integration

## Tutorial Format

Each tutorial follows a consistent structure:

1. **Goal** - What you'll accomplish
2. **Prerequisites** - What you need before starting
3. **Steps** - Detailed instructions with screenshots
4. **Expected Output** - What success looks like
5. **Troubleshooting** - Common issues and solutions
6. **Next Steps** - Where to go from here
