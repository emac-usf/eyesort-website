EyeSort 1.0 is the current stable release of the EEGLAB plugin for behavior-contingent fixation-event labeling in synchronized EEG and eye-tracking reading data.

## What version 1.0 provides

- Text-based interest-area mapping for single-line, fixed-width sentence stimuli
- Trial-level region, word, pass, and fixation-sequence metadata
- Queue-based fixation labels using region, pass, fixation type, and saccade-direction context
- Canonical six-digit `CCRRLL` codes with preserved original event types
- Optional BINLISTER-compatible BDF generation
- Single-dataset and one-at-a-time batch processing
- Saved configurations and exported MATLAB processing scripts

## Scope

EyeSort 1.0 assigns labels to fixation events. Saccade direction can be used as selection context, but EyeSort does not label saccade events themselves. The release supports text-defined regions; image/pixel-coordinate interest areas are not implemented.
