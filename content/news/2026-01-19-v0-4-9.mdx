# EyeSort v0.4.9 Released

We're pleased to announce the release of EyeSort v0.4.9, the latest stable version of our EEGLAB plugin for region-aware eye-tracking event labeling.

## What's New

### Improvements

- **Enhanced menu system** - More robust menu state management and error handling
- **Batch processing workflow** - Improved batch mode with better file validation
- **Configuration persistence** - Automatic saving of last-used configurations
- **Better error messages** - More helpful error reporting and validation

### Bug Fixes

- Fixed issues with duplicate menu creation
- Improved dataset validation when loading multiple files
- Resolved path handling edge cases

## Upgrading from Previous Versions

If you're upgrading from an earlier version:

1. Backup your old EyeSort folder
2. Delete the old version from `eeglab/plugins/`
3. Copy the new EyeSort folder into `plugins/`
4. Restart EEGLAB

Your saved configuration files should work with the new version.

## Known Issues
